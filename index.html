About Me

Aditi Rao

Frontend Developer & UI Engineer, Pune

I build interfaces that feel obvious in hindsight. Over the last four years I've worked across fintech dashboards, e-commerce storefronts, and internal tools, mostly living at the intersection of design and JavaScript. I care about pages that load fast, read clearly, and hold up on a cracked phone screen at 2G speeds just as well as on a widescreen monitor.

Outside of client work, I mentor early-career developers, maintain a small open-source component library, and am slowly teaching myself woodworking — which, it turns out, has a lot in common with laying out a grid.

Project Details

A few things I've shipped recently.

Ledgerly — Expense Dashboard

A budgeting dashboard for small teams, built with React and D3 charts, that turns raw transaction exports into a monthly burn-rate story anyone on the team can read in under a minute.

React · D3.js · Node.js

Marketplace Storefront Revamp

Rebuilt the checkout flow for a mid-size marketplace, cutting cart abandonment by simplifying form validation and adding inline error recovery instead of full-page reloads.

JavaScript · CSS Grid · REST APIs

Component Library — "Kiln"

An open-source set of accessible, themeable UI components used across three internal products, with full keyboard navigation and automated visual regression tests.

TypeScript · Storybook · Jest
